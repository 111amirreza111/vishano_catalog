# پنل مدیریت کاتالوگ محصولات

یک برنامه تحت وب کامل برای مدیریت کاتالوگ محصولات با قابلیت ذخیره‌سازی محلی، تولید PDF و دانلود تصاویر.

## ویژگی‌ها

- **مدیریت محصولات**: افزودن، ویرایش و حذف محصولات نامحدود
- **تصاویر محصولات**: آپلود تصاویر با حفظ ابعاد اصلی
- **توضیحات پویا**: افزودن چندین آیتم توضیحات برای هر محصول
- **محاسبه خودکار قیمت**: محاسبه قیمت نقدی و اقساطی بر اساس درصد تنظیم شده
- **تنظیمات درصد**: تنظیم درصد افزایش قیمت نقدی و اقساطی
- **دانلود PDF کاتالوگ**: تولید کاتالوگ PDF حرفه‌ای با طراحی زیبا
- **لایو کاتالوگ**: مشاهده زنده کاتالوگ با قابلیت دانلود تصویر هر محصول
- **ذخیره‌سازی محلی**: تمام داده‌ها در localStorage مرورگر ذخیره می‌شوند

## نحوه استفاده

1. فایل `index.html` را در مرورگر باز کنید
2. در صفحه **تنظیمات**، درصد افزایش قیمت نقدی و اقساطی را تنظیم کنید
3. در صفحه **محصولات**، روی دکمه "افزودن محصول جدید" کلیک کنید
4. تصویر محصول، نام، توضیحات و قیمت تمام شده را وارد کنید
5. قیمت‌ها به صورت خودکار محاسبه می‌شوند
6. محصول را ذخیره کنید
7. در صفحه **دانلود کاتالوگ PDF**، کاتالوگ کامل را دانلود کنید
8. در صفحه **مشاهده لایو کاتالوگ**، می‌توانید تصویر هر محصول را به صورت جداگانه دانلود کنید

## فایل‌ها

- `index.html` - فایل اصلی HTML
- `style.css` - استایل‌ها و طراحی
- `app.js` - منطق برنامه و جاوااسکریپت
- `README.md` - راهنمای استفاده

## تکنولوژی‌ها

- HTML5
- CSS3
- Vanilla JavaScript
- localStorage API
- html2canvas.js (برای کپچر تصاویر)
- html2pdf.js (برای تولید PDF)
- Vazirmatn Font (فونت فارسی)

## طراحی

- رنگ اصلی: سبز (#00CC77)
- طراحی مینیمال و مدرن
- کاملاً راست‌چین (RTL)
- واکنش‌گرا (Responsive)
- رابط کاربری تمیز و حرفه‌ای

## نکات مهم

- تصاویر با ابعاد اصلی ذخیره و نمایش داده می‌شوند
- تمام قیمت‌ها با جداکننده هزارگان نمایش داده می‌شوند
- داده‌ها به صورت JSON در localStorage ذخیره می‌شوند
- برنامه کاملاً آفلاین کار می‌کند (پس از بارگذاری اولیه)
