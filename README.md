# پنل مدیریت کاتالوگ محصولات

یک برنامه تحت وب کامل برای مدیریت کاتالوگ محصولات با ذخیره‌سازی فایل‌بندی شده و دانلود تصاویر.

## ویژگی‌ها

- **مدیریت محصولات**: افزودن، ویرایش و حذف محصولات نامحدود
- **تصاویر محصولات**: آپلود تصاویر با ذخیره در پوشه uploads
- **توضیحات پویا**: افزودن چندین آیتم توضیحات برای هر محصول
- **محاسبه خودکار قیمت**: محاسبه قیمت بر اساس درصد تنظیم شده
- **تنظیمات درصد**: تنظیم درصد افزایش قیمت
- **لایو کاتالوگ**: مشاهده زنده کاتالوگ با قابلیت دانلود تصویر هر محصول
- **ذخیره‌سازی فایل‌بندی شده**: تمام داده‌ها در فایل‌های JSON و تصاویر در پوشه جداگانه ذخیره می‌شوند
- **پایداری داده‌ها**: اطلاعات در تمام مرورگرها و رفرش‌ها حفظ می‌شود

## نصب و راه‌اندازی

### پیش‌نیازها
- Node.js (نسخه 14 یا بالاتر)

### مراحل نصب

1. نصب وابستگی‌ها:
```bash
npm install
```

2. اجرای سرور:
```bash
npm start
```

3. باز کردن مرورگر:
```
http://localhost:3000
```

**نکته**: سرور روی پورت 3000 اجرا می‌شود. می‌توانید فایل `server.js` را ویرایش کنید تا پورت را تغییر دهید.

## نحوه استفاده

1. سرور را با دستور `npm start` اجرا کنید
2. فایل `index.html` را در مرورگر باز کنید (یا به http://localhost:3000 بروید)
3. در صفحه **تنظیمات**، درصد افزایش قیمت را تنظیم کنید
4. در صفحه **محصولات**، روی دکمه "افزودن محصول جدید" کلیک کنید
5. تصویر محصول، نام، توضیحات و قیمت تمام شده را وارد کنید
6. قیمت‌ها به صورت خودکار محاسبه می‌شوند
7. محصول را ذخیره کنید
8. در صفحه **مشاهده لایو کاتالوگ**، می‌توانید تصویر هر محصول را به صورت جداگانه دانلود کنید

## ساختار پروژه

```
vishano_catalog/
├── data/                  # پوشه داده‌ها (ایجاد خودکار)
│   ├── products.json      # فایل ذخیره محصولات
│   └── settings.json      # فایل ذخیره تنظیمات
├── uploads/               # پوشه تصاویر آپلود شده (ایجاد خودکار)
├── index.html             # فایل اصلی HTML
├── style.css              # استایل‌ها و طراحی
├── app.js                 # منطق برنامه و جاوااسکریپت
├── server.js              # سرور Node.js و API
├── package.json           # وابستگی‌های Node.js
└── README.md              # راهنمای استفاده
```

## فایل‌ها

- `index.html` - فایل اصلی HTML
- `style.css` - استایل‌ها و طراحی
- `app.js` - منطق برنامه و جاوااسکریپت (فرانت‌اند)
- `server.js` - سرور Node.js و API endpoints
- `package.json` - وابستگی‌های پروژه
- `data/products.json` - ذخیره محصولات (ایجاد خودکار)
- `data/settings.json` - ذخیره تنظیمات (ایجاد خودکار)
- `uploads/` - پوشه تصاویر آپلود شده (ایجاد خودکار)
- `README.md` - راهنمای استفاده

- Vazirmatn Font (فونت فارسی)

### بک‌اند

- CORS (برای ارتباط بین سرور و کلاینت)

## API Endpoints

- `GET /api/products` - دریافت همه محصولات
- `GET /api/products/:id` - دریافت یک محصول
- `POST /api/products` - ایجاد محصول جدید
- `PUT /api/products/:id` - ویرایش محصول
- `DELETE /api/products/:id` - حذف محصول
- `GET /api/settings` - دریافت تنظیمات
- `PUT /api/settings` - بروزرسانی تنظیمات
- `GET /uploads/:filename` - دسترسی به تصاویر

## نکات مهم

- تصاویر در پوشه `uploads/` ذخیره می‌شوند
- داده‌های محصولات در فایل `data/products.json` ذخیره می‌شوند
- تنظیمات در فایل `data/settings.json` ذخیره می‌شوند
- تمام قیمت‌ها با جداکننده هزارگان نمایش داده می‌شوند
- تغییر تنظیمات قیمت باعث بروزرسانی خودکار قیمت همه محصولات می‌شود
- اطلاعات در تمام مرورگرها و رفرش‌ها حفظ می‌شود (دیگر وابسته به localStorage نیست)
